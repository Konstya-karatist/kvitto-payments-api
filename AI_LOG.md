# Работа с ИИ

Использовал Codex — GPT-5.6 Sol, уровень рассуждений High — и ChatGPT
для объяснений и разбора кода.

Три ключевых запроса, приведённые в сокращённой формулировке:

1. По PDF создать минимальный каркас на FastAPI, Pydantic v2, SQLAlchemy
   и SQLite. Расчёты и обработчики пока оставить для следующих этапов.
2. Проверить написанные мной функции скидки и графика, добавить тесты
   и реализовать платежи с валидацией и защитой от повторного создания
   по `Idempotency-Key`.
3. Проверить собранный мной вебхук, реализовать бонусы из PDF
   и сверить весь проект с заданием, включая документацию и чистый запуск.

Я вручную написал `calculate_discount` и `calculate_schedule` с подсказками
ChatGPT. Функцию `is_transition_allowed` предложил ChatGPT; я внёс её
и разобрал логику. Обработчик вебхука собирал вручную по объяснениям
и фрагментам кода. Codex помог с каркасом, остальными маршрутами,
тестами, бонусами, исправлением отступа и итоговым ревью.

Слабое предложение ИИ: первоначально статус обновлялся безусловным
присваиванием. При разборе одновременных вебхуков обнаружили риск
перезаписи результата. Заменили его условным `UPDATE` по ID и прежнему
статусу; конкурентный тест проверяет, что один запрос получает 200,
а второй — 409.

Я проверил API через Swagger и сохранение платежа после пересоздания
Docker-контейнера. Codex проверил чистую установку, миграции, HTTP-сценарии
и 93 теста. GitHub Actions успешно выполнил Ruff и pytest
на Python 3.11 и 3.13.
