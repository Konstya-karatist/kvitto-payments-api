# Работа с ИИ

Использовались ChatGPT (точная модель неизвестна) и Codex: модель GPT-5.6 Sol,
уровень рассуждений High.

Три ключевых запроса из истории, здесь приведены в сокращённой формулировке:

1. Прочитать PDF и создать минимальный каркас FastAPI, Pydantic v2, SQLAlchemy и
   SQLite, оставив расчёты, платежи, вебхук и бонусы для следующих этапов.
2. Проверить написанные пользователем функции скидки и графика, добавить тесты,
   затем реализовать платежи с валидацией, хранением сумм и конкурентно
   защищённым `Idempotency-Key`.
3. Проверить собранный пользователем вебхук и его конкурентный `UPDATE`, после
   чего реализовать бонусы PDF и провести итоговый аудит с чистым запуском,
   миграциями, Docker и реальными HTTP-запросами.

Пользователь вручную написал `calculate_discount` и `calculate_schedule` с
подсказками ChatGPT и проверил их через терминал. `is_transition_allowed` была
предложена ChatGPT, затем пользователь внёс функцию и разобрал её. Обработчик
вебхука пользователь собирал вручную по объяснениям и фрагментам ChatGPT: поиск
платежа, ответы 404/409, условный `UPDATE`, проверка `rowcount`, rollback, commit
и успешный ответ. Codex исправил отступ в обработчике, помог с каркасом,
остальными маршрутами, тестами, HMAC, фильтрами, Alembic, Compose, Ruff, CI,
документацией и финальным ревью.

Подтверждённое слабое решение ИИ: ранний вариант менял статус безусловным
присваиванием. Его заменили на `UPDATE` по ID и прежнему статусу, чтобы два
одновременно пришедших вебхука не могли последовательно перезаписать результат.
Проблему выявили при разборе конкуренции и закрепили синхронизированным тестом.

Пользователь вручную проверял API через Swagger и Docker Compose; в частности,
он подтвердил сохранение платежа после `docker compose down` и повторного старта.
Codex отдельно запускал Ruff, 93 теста на Python 3.13 и 3.11, миграцию на чистой
БД, чистую установку с новым venv, Uvicorn и изолированный Compose project с
подписанным вебхуком и проверкой сохранения данных. GitHub Actions на GitHub ещё
не запускался.
