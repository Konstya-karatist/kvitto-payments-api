# Правила работы с проектом

- Основной источник требований — PDF тестового задания, предоставляемый
  отдельно и не включённый в репозиторий. Если он недоступен, не заявлять
  о проверке полного соответствия заданию.
- Все денежные суммы в API, Python и БД хранятся целыми копейками; `float`
  использовать нельзя.
- Сохранять точные HTTP-статусы и тела ответов, указанные в задании.
- Поддерживать понятную структуру без ненужных слоёв и абстракций.
- Для каждого запроса использовать отдельную SQLAlchemy-сессию и закрывать её.
- Сохранять UNIQUE для `idempotency_key` и обработку конкурентного INSERT.
- Сохранять условный UPDATE статуса по ID и прежнему статусу для защиты от
  конкурентных вебхуков.
- После изменений запускать относящиеся к ним тесты, затем полный pytest и Ruff.
- В `AI_LOG.md` записывать только фактическую работу и реальные проверки.
- Не публиковать репозиторий, не отправлять работу и не выполнять деплой без
  прямого указания пользователя.
